Where to look

How the ranking works. Each source is scored on the model it covers, the kind of part it stocks, whether it deals in your part-number format, how far away it is, the condition of parts it sells, and how deep its catalogue is. Open “Why this ranking” on any result to see the full breakdown.

A caveat worth reading. This is a curated directory, not a live stock feed — it tells you where to look, it can’t tell you what’s on the shelf. Where a shop’s own search URL hasn’t been confirmed, the link falls back to a Google search scoped to that site, which always works. Run npm run check-links to spot entries that have gone stale.
